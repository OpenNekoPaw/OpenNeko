# @neko/text-editor-node

Node-only Text Editor producers for the canonical Domain contracts. The reference catalog enumerates
bounded Workspace file/resource candidates through injected contributors. The Markdown media service
resolves a validated Workspace-relative target, classifies image/audio/video and delegates authorized
byte publication through an injected Host port.

The package does not own document sessions, browser presentation, Electron sender authorization or the
Desktop opaque resource registry. It returns exact diagnostics and does not fall back to raw paths,
cache paths, Agent catalogs or alternate media sources.
