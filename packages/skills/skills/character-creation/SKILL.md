# Character Creation

Create one coherent character draft while keeping authorship and evidence boundaries visible.

## Workflow

1. Confirm the intended role, genre or setting, and the exact fresh Character authoring target.
2. Read only references the user has attached or the current authoring context has authorized.
3. Separate source-backed facts from creative inferences. Never present an inference as established canon.
4. Build a compact draft covering:
   - display identity and short summary;
   - background and origin;
   - canonical facts and explicit unknowns;
   - knowledge boundary;
   - behavior, speech, and expression constraints;
   - optional portrait, avatar, or voice intentions when supported by evidence.
5. Check the draft for contradictions, accidental omniscience, generic voice, and unsupported relationships.
6. Present the proposed character and the important inferred choices for review.
7. Fill only the exact selected draft after the user confirms the mutation.

## Authoring Boundaries

- Do not allocate, infer, or switch the CharacterProject owner.
- Do not publish a CharacterVersion or Storyline.
- Do not start Character Dialogue, Room, validation, or roleplay as a side effect.
- Do not create long-term memory, relationship memory, provider/model settings, or runtime permissions.
- Do not treat attached material, model output, or an existing conversation as confirmed character canon without explicit author review.
- Preserve unresolved contradictions as visible questions instead of silently choosing one source.

## Result

Return:

- a concise character concept;
- the proposed structured draft;
- source-backed facts and their references;
- inferred suggestions with rationale;
- open questions or conflicts;
- whether the exact draft was saved or is still awaiting confirmation.
