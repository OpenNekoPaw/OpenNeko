# Project Proposal Guide

## 中文指南

说明受众/目标、价值、范围、具体交付物和影响验收的约束。里程碑、owner、预算、依赖、备选和风险矩阵只在用于审批、融资、协作或正式评审时加入；数字和承诺不得编造，估算与假设必须标记。三个以上交付物、里程碑、成本项或方案需要精确比较时使用表格，判断性推荐放在表格外。

## English guidance

State the audience or objective, value, scope, concrete deliverables, and constraints that affect acceptance.

Add milestones, ownership, budget, dependencies, alternatives, and a risk matrix only when the proposal is meant for approval, funding, coordination, or formal review. Do not invent numbers or commitments; label estimates and assumptions.

Use a table when three or more deliverables, milestones, cost items, or options need exact comparison. Keep the recommendation outside the table when judgment is required.
