# 提示词包指南

## 中文指南

明确目标模型或 Tool 的角色、必需输入、每个引用的单一角色、一个可直接使用的提示词/操作意图、必要参数或负向约束、预期输出、可观察验收和入选结果的下一个消费者。只保留所选能力和任务相关细节，保留用户事实与引用角色，不伪造缺失输入。只有用户要求或比较本身是交付物时才生成变体、平台语法、镜头矩阵或参数扫描；单个提示词保持为可复制代码块和简短用法说明。没有明确消费者的分析不进入提示词包。

整理制作项目的提示词交接时，保留领域准备已形成的完整提示词、实体与状态、识别性结构、参考职责和未解决项，不能润色成通用形象标签或替不确定部件定型。可复用提示词是创作产物，不是工具日志；按当前授权写入对应工作区文档，保留实际生成记录与结果的关联。文档正文、节点中的请求记录与聊天答复承担不同职责，不能以其中一个已存在就声称另一个已交付。纯文案咨询仍可直接回答，不强制保存文件。
