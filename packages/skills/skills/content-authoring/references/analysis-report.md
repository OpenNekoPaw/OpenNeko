# Analysis Report Guide

## 中文指南

结论先行，并用最小充分的来源证据支持，再说明影响和可执行建议。明确区分观察事实、来源主张、推断和未知项；只有正式或可审计报告才展开方法、完整证据表、替代解释、评分和限制。

诊断优先采用“证据 → 根因 → 最小有效改动 → 预期效果”。先推荐证据支持的最窄修正，只有局部修改无法解决 owning problem 时才建议结构性重构。理论名称、清单命中或分数不能替代来源证据。三个以上共享字段的发现可以使用表格，单一发现不要做一行表。

## English guidance

Lead with the conclusion. Support it with the smallest set of source-backed evidence, then state impact and a practical recommendation.

Separate observed facts, source claims, inferences, and unresolved unknowns. Add methodology, a complete evidence register, alternative explanations, scoring, or limitations when the user requests a formal or auditable report.

For diagnosis, prefer `evidence → root cause → smallest effective change → expected effect`. Start with the narrowest supported correction; recommend structural redesign only when the evidence shows that local changes cannot resolve the owning problem. A theory name, checklist hit or numerical score never substitutes for source evidence.

Use a table for three or more findings that share fields such as evidence, confidence, impact, and action. Do not turn a single finding into a one-row table.
