# 素材预处理

## 中文方法

创作提示词、负面提示词和编辑指令遵循用户明确配置或要求的创作语言；未明确时沿用当前创作文档语言，无文档时沿用用户语言。派生、修复与重做继承相同语言和设计语义，不自行切换英文。仅在用户要求或已验证的模型语言限制下转换提交语言，并保留可审核原文；转换不得新增、删减设计约束或丢失参考绑定。接口字段名、枚举值、资源标识与专有名称遵循原契约，不随正文翻译。

先确认当前制作范围的素材与逐镜生成意图覆盖，再为当前优先批次准备下游操作所需的真实输入。状态只属于这一次有界操作：`可提交／未执行`，或存在精确依赖缺口的 `阻塞`；它不代表整个预处理阶段已经完成。

1. 对时间型作品，先读取覆盖当前制作范围的权威镜头表；PV 默认覆盖整支 PV，长篇或 TV 默认覆盖创作者当前确认的一个剧集、段落或连续制作单元。不存在完整镜头范围时返回创意设计或分镜，而不是从第一镜开始猜测生产。独立图片、音频或其他单一素材请求，可以把用户明确指定的当前产物作为完整范围。建立紧凑的逐镜生产输入表：列出每镜的剧情节拍与适用世界规则、角色及状态、物品、场景及空间关系、风格、构图／首尾帧、动作姿态和声音，记录真实来源或精确缺口、预期参考素材、消费镜头、静帧生成／编辑意图状态、视频运动意图状态与当前素材状态。相同需求可以合并一行，但必须列全消费镜头；不得把尚未分析的镜头合并成“后续再准备”。通用标签、提示词描述、未解析路径和旧文档中的 ready 声明不算素材事实。
2. 按复用价值和成本推进：先从已验证来源提取身份、结构、材质、状态和空间关系，再设计跨镜复用的角色设定、关键物品、场景／世界拓扑和风格静态锚点，最后以这些锚点准备逐镜分镜构图、动作姿态及首尾帧。漫画改编默认保留可核验的设计信息，不锁死原面板的构图、遮挡、透视简化、结构断裂或人体失真；结合多个相关视角消除歧义。补出的不可见结构属于改编设计，不冒充来源事实。裁切、去字和扩边只是按需整理来源，不能替代人物、物品或场景设计；只有目标本身是原图清理／忠实复现时才以像素保留为主。参考集合必须足以支撑当前制作范围的身份、剧情因果、世界规则、空间连续性和镜头设计；“有一张氛围图”不等于基础参考完整。生产性视频生成排在这些共享依赖与逐镜生成意图之后。每个现有素材只按可观察内容和绑定职责计入覆盖：一张首帧不能替代角色设定、关键物品、场景拓扑、动作状态和其他镜头构图。凡镜头表要求且会影响身份、物品、空间拓扑、动作因果、构图或连续性的静态输入，没有真实等价素材时就是关键缺口。不同作品不强求固定类别或数量，但关键静态缺口未解决时，必须继续准备静态素材，不能因为某个镜头已有首帧而默认选择视频，也不能把单张静帧、单镜准备包或技术试镜称为预处理完成。
3. 从逐镜生产输入表中选择当前最高优先级的一组兼容素材或逐镜提示词缺口作为一个有界批次。选择前重新以当前镜头表和真实素材计算覆盖；既有单镜输入包或“可提交／未执行”状态只描述原操作，不能作为阶段 authority。当前制作范围仍有关键静态缺口或逐镜生成意图缺口时，默认候选批次不得是视频；只有用户明确要求提前试镜时才允许例外。批次可以包含多个同阶段、同能力且彼此无结果依赖的素材操作，即使当前 Tool schema 的一次请求只接受一个结果；每项仍须分别满足 schema，并编译为一次独立调用。不要因为 schema 是单素材请求就把当前批次截断为第一项，也不要把不同角色、场景或镜头合成一个 prompt。不同媒体类型、不兼容引用以及依赖本批输出的操作拆成后续依赖批次。若一个 `SHxx` 含硬切、蒙太奇或多个独立景别，先回到分镜拆成多个镜头，不能把多镜序列包装成一个可执行单元。时长、比例、运动强度等不会改变故事、角色、交付边界或外部状态的可逆默认值可以明确写出并继续；实质创意选择缺失时阻塞。没有可靠价格能力时，不要求预算估算或预算授权。
4. 为批次中的每项分别绑定精确来源、素材或镜头目标和一个下游生成能力，并读取对应生成 Skill 与当前 Tool schema。若目标包含“先生成静帧，再用该静帧生成视频”等串行依赖，只把当前已有真实输入支持的最早依赖波次放入本批；后续操作只能记录依赖与保留约束，不能共享当前状态或交接包。operation、字段名、引用角色和限制只能来自当前 schema。
5. 区分漫画来源、可复用设计参考与逐镜首帧。角色／物品设定可以是竖幅、方幅、多视图或细节图，场景参考应表达可解释的空间连接；按各自职责验收，不把整片 16:9 规格强加给所有参考图。仅逐镜构图和首尾帧服从对应镜头画幅。带分格、对白或页边的原页可以作为图像生成／编辑的来源，不是视频首帧；根据当前能力准备重新设计、重构或清理的输入，缺少独立裁切工具不等于无法生成设计素材。本 Skill 只准备这些操作，不执行。检查输入真实内容与授权状态后，若仍无法完成目标，返回精确缺口。
6. 每个参考只承担一个职责：身份、当前状态、空间/构图、风格、运动或声音。写清必须继承与必须忽略的内容。设计参考须检查人物身份与形体、物品结构／持握关系、场景拓扑、姿态和跨镜一致性；文件可读取、尺寸或媒体探测通过，只是技术检查，不代表设计通过。重新计算整个制作范围的覆盖，不能因首批若干图片生成成功或去字完成便进入视频。
7. 预处理完成前必须为当前制作范围的每个镜头写清两项生成意图：若需要生成或编辑静帧，提供只描述一个时刻的图像提示词；若已有可直接使用且无需图像操作的真实素材，明确记为“不需要图像操作”并绑定该素材。每镜还必须提供视频运动意图，覆盖起始状态、主体运动、机位运动、环境变化、声音／静音、时长和约束。图像提示词与视频提示词不能合并为一个通用提示词，也不能用镜头摘要或参考标签代替。
8. 逐镜生产输入表可以先保存这些创作意图，但只编译当前批次中每项操作各自可消费的 prompt 或结构化输入；不得把整批合成一个调用。当前批次是图像生成时，每项静帧提示词不写时长、镜头运动、转场或连续动作；对应镜头的视频运动意图仍只是后续依赖，不能获得第二个 `可提交／未执行` 状态。当前批次是视频生成时，除非是用户明确要求的提前试镜，否则当前制作范围的关键静态素材覆盖和全部逐镜生成意图必须已经完成；此外每项还必须存在可直接消费的首帧或起始状态，并且该镜所需角色状态、物品、场景空间与连续性参考已经稳定绑定，再按当前 schema 分别编译有界视频输入。声音输入同理独立处理，不与图像或视频操作共享状态。
9. 只有真实输入可直接消费且当前 schema 已确认时，才为对应批次项返回 `可提交／未执行`；批次中某项阻塞不应抹去其他独立就绪项。内部必须按当前 schema 为每项编译完整 Tool 调用封装，并区分顶层 operation、媒体 request operation、必填 wrapper 与稳定输入 locator；实际封装只进入真实 Tool 调用或 owning capability 的结构化对象。默认面向创作者的交接展示当前批次的全部独立项、稳定素材及职责、各项可直接使用的提示词或操作意图、预期产物、直接验收、消费镜头、项目内依赖关系，以及逐镜生产输入表中仍未解决的下一依赖批次，不打印 Tool 名、字段名、原始 locator、运行时 ID、参数表或 JSON。只有用户明确要求调试、审计、复现或复制调用时才展示对应技术细节。验收不得放宽上游创意合同中的数值或连续性约束；未执行的调用不得声称已生成或已验证。
10. 缺少真实输入、稳定引用、当前 schema 或实质创意决定时，状态为 `阻塞`。不要生成候选调用包、模拟参数或重复创意分析；只在 Agent 对话中说明一个精确缺口和最小下一动作，保持正式创作文档不被阻塞信息污染。无限定“继续”优先处理逐镜生产输入表中当前阶段的下一批关键缺口，不得跳到视频、后期或交付。用户明确要求提前视频试验时，可以准备该有界操作，但必须标明它不完成预处理覆盖。

“设计完成”“可进入素材预处理”“已有提示词草案”或“一个素材包可提交”都不等于整个预处理阶段完成。面向创作者的交接可以隐藏原始 locator 和 schema 字段，但必须显示可解析的 Workspace 文件、Canvas 节点或已准备资产名称及其职责；只写“参考职责”而没有实际资源，不算绑定。创作文档里的代码样式路径或来源说明只是追踪信息，不自动证明资源引用已经绑定；只有 owning 文档语法可解析的引用、当前操作对象中的稳定绑定，或已物化的 Workspace/Canvas 资产才算真实绑定，不得发明内部选择器的 Markdown 引用语法。只有这个真实资源能被当前下游能力直接消费时，才可称为可执行输入单元。一个素材准备单元不得同时把图像生成和依赖其结果的视频生成标成 `可提交／未执行`。

## 基础资产先于镜头首帧

先核对上游人物／剧情／物品／地点证据是否支持当前制作范围；只有“旅人、武器、巨构”等标签、漫画页和镜头表，不证明角色身份与资产设计已完成。缺少会改变当前输入的来源证据时，返回该具体分析缺口；已有可靠分析直接复用，不重复全卷阅读。

以人物、物品和场景为单位建立跨镜复用的基础资产清单，并关联逐镜表。每项区分来源参考、已写设计意图、待生成设计、真实候选、已检查和创作者选定，记录所需视角／状态、目标美术、实际产物引用和全部消费镜头。漫画来源存在或提示词已写不能把“待生成设计”记为“素材已完成”；只有真实等价设计已经存在时才跳过生成。准备 Skill 仍只编译当前静态设计批次，由执行编排调用图像能力生成并检查。

共享身份／空间尚未定型时，多个含相同人物、物品或地点的分镜首帧不是独立就绪项。先为缺失的基础资产准备批次，再基于真实选定设计派生视角／状态和镜头构图；设计提示词不能被首帧提示词代替。明确的技术试镜可以缩小消费范围或接受已说明的实验性缺口，但不能冒称缺失资产已生成、试镜等于整片预处理完成。试镜仍按其实际检查目标区分需要固定的身份／空间与允许探索的变量。

## 目标美术与多视图覆盖

素材设计沿用已确认的目标美术，而不是默认继承来源媒介。把必须保留的身份、轮廓、结构和空间关系，与目标的造型方式、色彩、材质、光照、体积和完成度分开描述，并落实到每项生成提示词与验收。漫画排线、网点、灰阶和纸张纹理只有在目标美术要求时才继承；不能用来源线稿代替需要完整材质与光影的设计。黑白或线稿本身并非不适合动画，用户明确选择时应保留。没有足以决定素材外观的目标美术时，先提出可评审的美术方向或在获准范围内准备风格样张，不擅自选择写实、3D 或彩色，也不大批量生成未定型资产。

对需要跨镜复用的人物、物品，建立按实体组织的视角／状态覆盖，而不是只准备一张情境插画。每项记录消费镜头、所需视角或状态、可见结构、共享造型约束、真实参考或缺口、独立提示词和验收：

- 人物按镜头需要覆盖正面、侧面、背面、四分之三视角，以及会影响表演的头部／表情、服装装备细节和动作姿态；不要求无用途的固定全套，但不能用单一侧影代表背部与正面已完成。
- 物品按可见面、尺度、装配与使用方式覆盖必要正侧背／俯视、结构细节、开关或展开状态，以及与人物的持握／佩戴关系；只补制作实际需要的结构，不虚构机械内部。
- 场景覆盖布局与通路、关键方向、连接部位和尺度参照；美观的透视画不能代替可解释的空间拓扑。

多视图必须属于同一设计：比例、体积、左右非对称、装备位置、材质与色彩跨视角一致。已有合格锚点时直接复用；没有时先定主体设计，再以选定锚点派生其余视角，不把尚未定型的同一人物各角度当作互不相关的并行设计。独立实体仍可组成并行批次。未被来源展示的部位明确标为待确认的改编设计，不冒充原作事实。

可以交付同一实体的多视图设定板，但必须保证视图可辨、尺度可比较，并为下游绑定可独立消费的视角图或可解析区域；不能把多视图板直接当视频首帧。多视图静态设定不是动作蒙太奇；每个独立生成项仍遵循当前能力支持的单一产物边界。文字列出视角只是准备需求，不等于已有这些图像。

进入逐镜构图前检查设计的视角／状态覆盖和跨视角一致性，进入视频前再检查对应单帧与整体静态依赖。区分结构草图、目标美术设计参考和逐镜首帧：草图可以证明结构，但不能代替目标完成度；竖幅人物设定可以合格，但不能代替横幅镜头。关键视角、状态、目标美术或交互关系缺失时，下一批仍是静态设计，而非视频。
