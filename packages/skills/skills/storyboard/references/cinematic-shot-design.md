# Cinematic Shot Design

## 中文指南

当散文、剧本、场景描述或已批准改编节拍需要电影化镜头决定时使用。先采用能让叙事变化可读的最少镜头数，不默认九宫格、三幕、景别交替或自动镜头序列；只有新增信息、情绪/关系变化、动作结果、揭示、空间建立或必要转场时才增加镜头。

每个镜头明确叙事任务、可见瞬间、因叙事而选择的景别/高度/角度/方向/运动、前中后景与视线/轴线、动机光和材质、进出状态与剪辑接点。时长只在表演、动作、对白或节奏证据支持时给出。来源未规定的机位、光线、时长和转场必须标为导演提案；生成提示词应表达已选画面与引用角色，不能用导演名、器材名和泛化质量词代替构图与动作。

## English guidance

Use this guide when prose, a script, a scene description or approved adaptation beats need cinematic shot decisions.

Start from the smallest shot count that makes the narrative change readable. Do not default to a 3×3 grid, three-act pattern, alternating shot sizes or automatic lens sequence. Add a shot only when it contributes new information, a change in emotion or relationship, an action result, a reveal, spatial orientation or a necessary transition.

For each useful shot decide:

- narrative task: what becomes newly visible, understood or felt;
- visible moment: subject, readable action and the instant worth framing;
- camera rationale: shot size, camera height, angle, orientation and movement because of the narrative task;
- spatial logic: foreground/midground/background, eyelines, screen direction, axis and important negative space;
- light and material: motivated key light, time/weather, reflections and story-relevant texture;
- continuity and edit: incoming state, outgoing state, action match, prop/wardrobe state and cut or transition intent;
- duration guidance only when supported by performance, action, dialogue or pacing evidence.

Keep observed source facts separate from directorial proposals. If source evidence does not establish a camera, duration, lighting or transition choice, label it as a proposal instead of presenting it as source truth.

Write generation prompts only after the shot decisions are coherent. A prompt should express the selected visible moment and reference roles; it should not substitute a stack of director names, camera brands, film stocks or generic quality adjectives for composition and action.

Before delivery, check that shot-size changes serve the scene, camera position is spatially possible, close framing states its focal detail, action and eyelines cross cuts coherently, and no fixed template has created redundant shots.
