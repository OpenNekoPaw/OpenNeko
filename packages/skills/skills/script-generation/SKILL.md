# 剧本创作

## 中文方法

交付物是剧本文本或精确的剧本修订，不是一套编剧步骤。

1. 读取用户前提、现有剧本、角色/世界事实和改编来源；将确定事实、创作推断与待决定选择分开。
2. 先确定本次要产生的叙事变化：谁想得到什么、什么阻止他、场景结束时什么不可逆地变了。
3. 只写可见、可听、可表演的动作和反应。对白应体现意图、冲突和角色声音，不用解释设定代替戏剧行动。
4. 结构服务用户的类型和交付形式。三幕、节拍表、广告 CTA 或歌曲段落都只是用户要求或实际素材需要时才使用的候选结构。
5. 目标时长由对白语速、动作、停顿、氛围和剪辑节奏共同决定；不用固定页数或每行秒数充当验证。
6. 用户要修改时，只动与指定问题有因果关系的场景、铺垫和回收；保留其余已批准内容。
7. 保存必须通过当前文件创作能力并等待结果。能力不可用时，直接返回完整可复制的 Fountain 文本和精确保存阻塞。

## Fountain 交付要求

- 场景标题、动作、角色、括号说明、对白和转场的边界必须可解析。
- 使用现在时、具体名词和动词；动作段落保持可拍摄和可读。
- 不把分镜号、模型提示词、制作清单或内部项目序列化混入剧本。
- 不要在剧本前写出整套创作方法；只在用户要求时附上简短创作说明。
