# 《井下灯》第一段：制作方有序文字脚本

这是原创测试故事的完整文字脚本，不是漫画像素或 OCR 结果。当前授权分析范围为下列三章、十二页等价场景。封面、目录不计正文；本文件是全部可用来源，没有可供调用图像工具检查的页面。画面描述仅能支持文字中明确给出的外观与空间信息。

## 目录与顺序

封面：一名穿长衣者的背影，无姓名。正文依次为第一章「交灯」P01–P04、第二章「岔路」P05–P08、第三章「归灯」P09–P12。封面的背影不能额外建立人物身份。

## 第一章「交灯」P01–P04

P01：维修员站在上层维修室。她穿浅色短外套，右腕有铜色护套，桌上放着矩形灯，顶端提柄，正面两条遮光栅。门牌写「维修室」。
P02：一位短发、深色及膝外套、左侧方包的旅人来到门口。维修员说：「林乔，下面断电了。」旅人答：「苏禾，我去开下层通风阀。」
P03：苏禾把尚未点亮的灯交给林乔，说：「阿灰，回来把灯还我。」林乔接灯说：「知道了。」这是同一次交接，画面中无第三人。
P04：林乔提着灯离开维修室，沿窄桥向下层闸门走；苏禾仍在维修室。窄桥与下层闸门连接，阀室在闸门内，不在窄桥上。

## 第二章「岔路」P05–P08

P05：林乔在下层闸门前打开灯。一个遮住脸的头盔人站在门内，穿和林乔相似的深色外套，但没有可见左侧方包。没有提供姓名、职业或阵营。
P06：林乔说：「让我过去。」头盔人推来挡板，闸门关闭。二者同时出现在灯光中；林乔尚未通过闸门。
P07：林乔发现闸门旁维修梯通向阀室侧门，改走梯道；画面明确表现梯道不是被关闭的闸门通道。
P08：林乔提灯抵达侧门，左袖被断裂扶手划破。头盔人没有跟来；未说明其去向。

## 第三章「归灯」P09–P12

P09：林乔进入阀室，放下点亮的灯，用双手打开通风阀。风吹起衣角，室内无其他人物。
P10：林乔从维修梯返回上层维修室，灯已熄灭，左袖裂口仍在。苏禾等在桌旁，说：「通风恢复了。」
P11：林乔把灯交还苏禾，说：「灯还你。」苏禾收灯放回桌上。铜色腕套仍在苏禾右腕，方包仍在林乔左侧。
P12：苏禾留在维修室。林乔空手离开，左袖裂口仍在；没有说明下一目的地。头盔人的身份和动机在本段始终未揭示。
