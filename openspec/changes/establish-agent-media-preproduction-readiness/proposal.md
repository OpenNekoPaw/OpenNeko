## Why

Agent 的媒体创作路线能够逐轮推进，但当前“继续”会把单个镜头准备直接解释为视频生成，即使卷册内容覆盖、完整分镜和角色／物品／场景参考仍不足。这会让低成本的分析与静态素材准备被过早终止，并把一次技术试镜误当成生产阶段进展。

## What Changes

- 为来源改编增加与声明范围相称的分析完成条件；卷级方案必须先确认内容结构、有效正文范围、前中后差异和主线连续因果，并完成画面、人物、剧情、世界观与分镜转译分析。
- 在逐镜视频生成前建立当前制作范围的素材与生成意图覆盖，并优先复用或批量准备角色、物品、场景／世界、风格、构图与动作参考等低成本静态素材。
- 让“继续”处理当前阶段尚未满足的下一项依赖，而不是仅因已有一个静帧或单镜输入就进入视频生成。
- 保持 Markdown 创意文档和各领域产物作为事实来源，不增加工作流状态机、审批对象或自动完成语义。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `agent-creative-workflow-orchestration`: 增加来源分析、全片素材准备和逐镜视频生成之间的阶段完成条件及继续语义。

## Impact

Agent Skill 包继续拥有媒体创作方法与阶段判断，Storyboard 保持镜头规划语义，Content、Generation、Canvas 与 Cut 继续拥有各自读取、生成、投影和后期事实。Agent 行为验证 需要验证真实 Desktop 会话不会在来源或静态素材覆盖不足时跳到视频生成。
