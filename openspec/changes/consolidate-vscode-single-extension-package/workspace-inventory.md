## Workspace and runtime inventory

Date: 2026-07-29

The canonical workspace discovery is limited to `apps/*` and `packages/*`.
Every row below is an immediate child of one of those roots. Package scripts
and exports remain authoritative in the referenced `package.json`; the
entrypoints listed here are the build/test commands that participate in this
change.

### Former nested package disposition

| Former responsibility                                                                | Final owner                                                                   |
| ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| Tools, Preview, Assets, Cut, Canvas and Agent extension manifests/activation entries | removed; `apps/neko-vscode/package.json` and `src/extension.ts` are canonical |
| VS Code commands, views, custom editors, panels, bridges and host adapters           | `apps/neko-vscode/src/features/<feature>`                                     |
| Agent runtime/types/test utilities/Webview/AI SDK/Platform                           | corresponding top-level `packages/*` rows above                               |
| Canvas and Cut domain/Webview packages                                               | corresponding top-level `packages/*` rows above                               |
| Preview and Tools Webview/contracts packages                                         | corresponding top-level `packages/*` rows above                               |
| feature-local VSIX scripts, manifests, `.vscodeignore` and extracted payload roots   | removed                                                                       |

No compatibility package, alias workspace, nested manifest or secondary
extension entry remains an accepted disposition.
