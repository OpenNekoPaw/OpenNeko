## 1. 镜头结果连续性

- [ ] 1.1 让创作者明确采用的 Generation 输出以稳定 Workspace 引用写回唯一 Markdown 镜头行，并保证预览候选不会自动进入下游。
- [ ] 1.2 验证镜头行缺失、重复或已冲突时仅当前绑定失败，既有候选、文档和其他镜头保持可用。

## 2. 视频候选审查

- [ ] 2.1 提供单个授权视频的有界总览和指定短时间段帧证据，保持抽帧结果瞬态且可追溯到精确时间戳。
- [ ] 2.2 验证 Agent 能基于真实帧完成采用、重做或进一步检查建议，并在非法范围、损坏流和无授权来源上 fail-local。

## 3. 时间线组装

- [ ] 3.1 让 Agent 通过 Cut owner 导入采用素材、调整片段顺序并设置受支持的基础转场，形成可直接人工评审的时间线。
- [ ] 3.2 验证所有组装操作只修改精确 Cut 文档，不建立 Canvas、Desktop 或 Agent 的平行 OTIO 写入路径。

## 4. 成片与交付

- [ ] 4.1 在既有导出结果上提供实测技术 QC、未验证项和简洁交付清单，不把未测量规范声明为通过。
- [ ] 4.2 验证从 Markdown 镜头表、采用素材、Cut 时间线到导出文件的完整人机协作路径，并在用户要求时发布可移植交付清单。
