## Product boundary

Core creative Skills share a concise-by-default content method with explicit expansion and handoff semantics. Skill content owns guidance and output shape; DSH owns discovery and composition; Tools and Host services retain execution and authority.

## Core invariants

- Ordinary requests produce the smallest useful artifact rather than exhaustive templates by default.
- Users can explicitly request deeper analysis, alternatives, structured plans, or supporting resources.
- Task-relevant guides compose without requiring every Skill or reference to load.
- Guidance cannot grant Tool visibility, permission, filesystem access, provider capability, or Host trust.
- Domain facts and generated artifacts remain owned by their canonical application services.

## Product acceptance

The capability is complete when representative core Skills produce consistent concise, expanded, resource-backed, and multi-Skill outcomes through the real Agent path.

## Non-goals

This change does not modify the DSH Skill format, add a private router, or force one universal document template.
