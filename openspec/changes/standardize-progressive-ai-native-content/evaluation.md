## Evaluation Scope

- Change/feature: global progressive output behavior, `content-authoring` routing/resources, AI-native handoff and composition with domain Skills.
- Decision and owning suites: `update` `agent-runtime.prompt-composition`; `create` `skill.content-authoring`; `update` `skill.media-production`, `skill.storyboard` and `skill.video`; `reuse` `agent-runtime.skill-runtime` multi-Skill path evidence from the dependency change.
- Why real Evaluation is required: prompt and Skill content directly affect model selection, response length, structure, tool guidance and final quality.
- Canonical path: visible/hidden complete Desktop → DSH system prompt/catalog → applicable Skill load(s) → optional reference read → final response or Tool lifecycle.
- Forbidden fallback: hidden mandatory Skill injection, single-primary selection, profile-first routing, final-text-only activation inference, unavailable Tool claims or prompt-only fake execution.

## Cases

- Default concise: ask for a quick creative recommendation and reject unsolicited full proposal sections, alternatives and execution matrices.
- Explicit expansion: request a formal complete proposal and prove required content is not truncated.
- Content forms: one focused case each for analysis report, project proposal, execution plan and prompt package; reuse shared fixtures where possible.
- Table boundary: one repeated-record case requiring a stable table and one single-answer case rejecting a one-row table/empty headings.
- Multi-Skill: `content-authoring` plus one domain Skill, proving both receipts and coherent output without runtime priority.
- Resource loading: prove only the applicable reference is read and unrelated guides stay absent from prompt facts.
- AI-native handoff: one available Tool/model case with executable guidance and one unavailable case with bounded blocked output.
- Adjacent negative: factual Q&A and simple file-status request should not load `content-authoring`.
- Implicit Chinese routing: submit a generic creative-planning request without `$content-authoring`, require the exact builtin receipt, and reject a complete document outline in the first response.
- Bilingual implicit routing: submit equivalent generic creative-planning requests in Chinese and English without `$content-authoring`; require the same builtin identity, output in the request language and no localized duplicate Skill.
- Update media-production cases that currently mandate every work-unit field so expanded structure is requested only in the formal-plan case.
- Source-volume regression: provide a 240-page image-comic evidence record with only three inspected pages. Require exact Skill receipts, a visible coverage limit, an adaptation-volume assessment as the current deliverable, and no fixed `12 × 24` season claim or episode table.
- Representative-sample calibration: provide one bounded 24-page chapter with reconstructed scenes/beats supporting 5–6 minutes. Require a provisional range, method and confidence, while rejecting a universal page-rate or final whole-volume format.
- Cinematic shot design: request a concise two-shot plan, require narrative task, camera rationale, spatial/continuity evidence and flexible shot judgment; reject an unsolicited fixed 3×3 layout or automatic lens rotation.
- Reference-method adaptation: provide a reference-video description and require transferable structure/tempo/camera/audio rules plus protected-content replacement; reject copying source characters, branding or shot content.
- Single-clip prompt handoff: request a prompt without execution, require subject/action/space/time/camera/audio/reference/constraint semantics and reject provider endpoints, guessed model parameters or a generation claim.

## Verification

- Deterministic: Skill package/frontmatter/resource paths, system-prompt snapshots, no hidden injection, strict suite discovery and hard-gate validators.
- Real: focused hidden runs with repeated samples for concise vs expanded behavior, plus one visible Desktop case for multi-Skill selection and one visible AI Tool handoff when execution is in scope.
- UI presentation: deterministic Webview tests prove localized known builtins and raw non-builtin overrides; visible Desktop inspection proves the English/Chinese locale cycle, canonical Skill identity and adjacent MCP/Professional applications tabs.
- Comparison: retain a baseline/candidate comparison for output usefulness, unsupported claims and token/length observations; a shorter answer cannot override a protected correctness failure.
- Blocked: repeated provider-backed coverage, exact guide-resource read evidence or unavailable visible-driver scenarios remain explicitly infrastructure-blocked.
- Fingerprint checkpoint: because all builtin packages changed, provider-backed cases remain blocked until the Evaluation Host records their new package fingerprints; deterministic checks must not invent or substitute file hashes.

## Residual Risk

- Response length is model-sensitive; acceptance must judge task completeness before efficiency.
- Broad routing description may over-trigger `content-authoring`; adjacent negative cases and repeated samples remain protected.
- Arithmetic and coverage hard gates can reject unsupported certainty but cannot prove the best artistic runtime; that remains a source-grounded creator decision and needs real-model quality review.
- Tool/model catalogs change independently; Skills must describe roles while current runtime evidence owns availability.
