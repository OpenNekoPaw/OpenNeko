### User data disposition

- Application settings 与 Shell state 已由 `@neko/host` contract/service 管理，并通过
  `@neko/local-metadata` repository 写入 canonical `~/.neko/neko.db`；Desktop 只负责迁移期旧文件
  adapter、启动 wiring 与 native theme/window projection。Provider secret 仍只经加密 credential port，
  不写入 projection、报告或测试 fixture。
- Workspace/project locator、`.nkc`、Media Library link 和可移植引用不因代码移动而改写；非法绝对路径、
  未知 schema 与旧 runtime handle 继续 fail-visible。
- SQLite/local metadata 使用唯一全局数据库与明确 workspace identity。valuable local state 采用显式迁移，
  rebuildable cache 允许重建；旧 workspace/package-local 数据库不作为成功 fallback。
- `asset-library` 到 `global-asset-library` 是预发布内部 wire owner identity 的一次性破坏性收敛，不迁移
  项目事实；旧 renderer message/owner path 被明确拒绝。
- Generation output index、Canvas 草稿和 local metadata 的历史数据只通过登记的 migration/recovery 入口
  处理；正常运行路径不 dual-read、dual-write 或静默兼容。

## Migration baseline

以下清单覆盖迁移前 `apps/neko-desktop/src/{main,preload,renderer,shared}` 的全部 96 个生产 TypeScript
模块、当时全部 28 个一级 workspace package，以及 `@neko/shared`、`@neko/platform` 的内部职责。

`D` = 当前放错位置的业务 owner。`D` 是迁移输入，不表示模块当前不可运行。

## Dependency-ordered bounded changes

### Shared contract transfer outcome

Task 4.4 is complete. All consumers use owning packages, every former Shared feature module is
absent, and `check:shared-exports` rejects direct, named-root, namespace, and dynamic-import bypasses.

Preview moved to `@neko/preview-domain`; Character to `@neko/chara`; Agent and prompt/MCP contracts
to `@neko/agent-contracts`; provider/model contracts to `@neko/ai-contracts`; Canvas/NKC to
`@neko/canvas-domain`; Assets, Content, Entity and Generation to their owning packages; theme/i18n
and diff presentation to `@neko/ui`; storage and SQLite contracts to `@neko/local-metadata`.
No compatibility re-export is retained.

每个切片必须同时完成 contract、实现、caller switch、旧路径删除和验证；不得只移动文件。

1. **Freeze/catalog**：role catalog、全 workspace dependency/export/alias/strict gate，禁止新增 Shared、
   Platform 和 app business owner。
2. **UI infrastructure**：Shared components/icons/React i18n → UI；不依赖领域迁移。
3. **Agent contracts/settings**：Shared Agent types + Platform effective config → Agent contracts/runtime；
   Desktop credential/repository 保持 concrete adapter。
4. **Generation**：Platform provider-neutral media generation/output lifecycle → Generation；AI SDK/provider adapter
   由 Desktop 注入；删除对应 Platform surface。
5. **Canvas**：Shared NKC/Canvas contracts + Desktop authoring/material action → Canvas domain/application/node；
   Canvas Webview aliases切换公开入口。
6. **Assets/Entity/Content**：Shared Assets/Content/Entity contracts、Desktop Resource Browser、Media Library
   sync/portability → 明确 domain/application/node/Webview owners；保护项目、symlink 和 SQLite。
7. **Cut/Preview/Media**：规范 family name/exports，把 Preview policy迁 domain，保留 Media root/node/browser；
   Desktop 只保留 `openneko:` authorization/registry。
8. **Tools 决策**：完成真实 Tools producer闭包或删除 inactive packages，不用空入口占位。
9. **Retained kernels**：Chara/Search/Quality 明确 retained 状态、显式 exports 和无自动注册；Agent test-utils
   合并或证明独立 consumer。
10. **Platform/Shared finalization**：Platform consumer归零后整体删除；Shared feature ledger归零后缩到最小
    infrastructure；移除所有临时 exception/source alias/wildcard。
11. **Desktop finalization**：shared 只留 executable contracts，所有 handler 只委托 package public port；
    运行真实 Electron lifecycle/security/user-data场景。

这些切片禁止建立 `@neko/desktop-core`、新 Shared/Platform facade、跨领域 generic manager 或双实现。
